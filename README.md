# Budget Tracker

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Finance Tool](https://img.shields.io/badge/finance-tool-green.svg)]()

A personal budget and expense tracking CLI with reports and budgets.

## ✨ Features

- **Track Expenses** - Record income and expenses
- **Categories** - Categorize transactions
- **Budgets** - Set monthly budgets with alerts
- **Reports** - Weekly/monthly/yearly spending reports
- **Visual Charts** - Text-based charts
- **Multiple Accounts** - Track multiple accounts
- **Import/Export** - CSV/JSON support
- **Savings Goals** - Set and track savings goals

## 📦 Installation

```bash
git clone https://github.com/Master-626/budget-tracker.git
cd budget-tracker
pip install .
```

## 🚀 Quick Start

```bash
# Add an expense
budget expense 25.50 -c food

# View summary
budget summary
```
